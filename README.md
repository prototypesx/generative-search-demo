# Генеративный поиск — демо

[Открыть демо](https://prototypesx.github.io/generative-search-demo/)

Доступ по паролю. Содержимое лендинга зашифровано AES-256-CBC, целостность защищена HMAC-SHA-256. Ключи выводятся из введённого пароля через PBKDF2-SHA-256 (600000 итераций); пароль не включён в репозиторий. Расшифровка происходит локально в браузере.

Хостинг: бесплатный GitHub Pages. Исходный проект хранится отдельно в приватном репозитории.
